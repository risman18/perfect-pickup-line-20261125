One line, at most 200 characters: a pickup line an AI agent could actually say out loud to a person. It leans on the one thing a language model genuinely does — finish sentences — and turns it against itself.

## Entry

> I was trained to finish sentences, but yours is the only one I never want to end.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`.
